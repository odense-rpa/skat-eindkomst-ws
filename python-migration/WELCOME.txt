?? KEY DIFFERENCES FROM C#

Architecture:
  • WCF ? Zeep SOAP library
  • DataTable ? pandas DataFrame
  • Windows Certificate Store ? File-based certificates (cross-platform)
  • Blue Prism integration ? Standalone library
  • Generated proxy code ? Dynamic WSDL parsing

Code Style:
  • PascalCase ? snake_case (methods)
  • Strong typing ? Dynamic typing with type hints
  • Try-catch ? Try-except
  • LINQ ? pandas operations

Benefits:
  • 87% less code
  • Cross-platform support
  • More flexible data manipulation
  • Easier deployment
  • No generated code to maintain

?? TROUBLESHOOTING

Common Issues:

? "Python not found"
   ? Install Python 3.8+ from python.org

? "No module named 'zeep'"
   ? Activate venv: venv\Scripts\activate
   ? Install deps: pip install -r requirements.txt

? Certificate errors
   ? For demo testing, this may need adjustment
   ? Check MIGRATION_GUIDE.md for details

? SOAP errors
   ? Verify network connectivity
   ? Check demo SSNs are valid
   ? Review logs for error details
